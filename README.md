# ReviMarket Global

**ReviMarket Global** — frontend **web application** / веб-приложение в стиле **black / purple neon**, объединяющее:

- фриланс-биржу;
- заказы для дизайнеров;
- раздел товаров и цифровых услуг;
- категории работ как на крупных биржах;
- предложения исполнителей;
- личный кабинет заказчика / исполнителя;
- чат заказчика и исполнителя;
- чат с поддержкой;
- статистику пользователя и всей платформы;
- оферту и правила площадки;
- developer logs для отладки.

## Статус проекта

Проект оформлен как **финальная frontend web application / Global Version** для портфолио.

Это публичное frontend-веб-приложение без серверного backend. Данные работают в браузере через `localStorage`, а пользователь перед входом принимает или отклоняет сохранение данных.

## Предложения исполнителей

Раздел **Предложения** — это витрина готовых услуг исполнителей.

Исполнитель может указать:

- название услуги;
- категорию;
- цену;
- срок выполнения;
- описание результата.

В будущей backend-версии это станет полноценной карточкой услуги с безопасной сделкой, отзывами, рейтингом и оплатой.

## Личный кабинет

В профиле есть расширенный кабинет:

- роль аккаунта;
- количество моих предложений;
- стоимость услуг;
- статус конфиденциальности;
- быстрые действия: создать заказ, фриланс-заказ, товар;
- быстрый переход к категориям, предложениям и оферте.

## Комиссия в оферте

В заготовке оферты указаны комиссии:

- заказ / фриланс-сделка — **10%**;
- цифровой товар / шаблон — **7%**;
- срочная сделка / продвижение — **12%**;
- вывод средств — **0%** со стороны платформы.

В текущей frontend-версии реальные платежи отключены. Перед реальным запуском оферту, возвраты, комиссии, налоги и обработку персональных данных нужно согласовать с юристом.
