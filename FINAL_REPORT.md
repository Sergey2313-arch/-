# ReviMarket Global — финальный отчёт проекта

## Название проекта

**ReviMarket Global**

## Тип проекта

Frontend MVP / Global Version фриланс-платформы и маркетплейса услуг.

## Краткое описание

ReviMarket Global — это frontend-платформа в стиле **black / purple neon**, которая объединяет:

- фриланс-биржу;
- заказы для дизайнеров;
- каталог цифровых товаров и услуг;
- категории работ;
- предложения исполнителей;
- личный кабинет;
- чат заказчика и исполнителя;
- чат поддержки;
- статистику платформы;
- оферту и правила площадки.

Проект сделан как финальная портфолио-работа и база для будущего backend-приложения.

## Цель проекта

Показать навыки создания интерфейса современной digital-платформы:

- структура SPA-интерфейса без фреймворков;
- работа с HTML, CSS и JavaScript;
- localStorage для данных frontend-версии;
- адаптивный интерфейс;
- логика ролей пользователя;
- UI для фриланс-биржи и маркетплейса;
- подготовка проекта к публикации через GitHub Pages.

- цифровой товар / шаблон — 7%;

## Ограничения текущей frontend-версии

Проект пока не использует backend. Это значит:

- нет серверной регистрации;
- нет настоящих паролей;
- нет серверной базы данных;
- нет реальных платежей;
- данные сохраняются в браузере;
- чаты не синхронизируются между разными пользователями.
