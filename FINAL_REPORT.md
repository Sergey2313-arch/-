# ReviMarket — финальный отчёт проекта

## Название проекта

**ReviMarket**

## Тип проекта

Frontend MVP / beta-версия фриланс-платформы и маркетплейса услуг.

## Краткое описание

ReviMarket — это демонстрационная frontend-платформа в стиле **black / purple neon**, которая объединяет:

- фриланс-биржу;
- заказы для дизайнеров;
- каталог цифровых товаров и услуг;
- категории работ;
- предложения исполнителей;
- личный кабинет;
- чат заказчика и исполнителя;
- чат поддержки;
- статистику платформы;
- оферту и правила площадки.

Проект сделан как портфолио-работа и база для будущего backend-приложения.

## Цель проекта

Показать навыки создания интерфейса современной digital-платформы:

- структура SPA-интерфейса без фреймворков;
- работа с HTML, CSS и JavaScript;
- localStorage для demo-данных;
- адаптивный интерфейс;
- логика ролей пользователя;
- UI для фриланс-биржи и маркетплейса;
- подготовка проекта к публикации через GitHub Pages.

## Ограничения beta-версии

Проект пока не использует backend. Это значит:

- нет настоящей регистрации;
- нет настоящих паролей;
- нет серверной базы данных;
- нет реальных платежей;
- данные сохраняются только в браузере;
- demo-чаты не синхронизируются между пользователями.
